# Hardware Overview

## Compute

- Raspberry Pi 5 (main system)

## Microcontrollers

- RP2040 (low-latency I/O)
- ESP32 (wireless control)

## Audio

- USB audio interface preferred
- External DAC support required

## Inputs

- MIDI USB + DIN
- GPIO buttons / encoders
- Sensors (IMU, piezo, touch)

## Display

- Primary: HDMI / LCD
- Secondary: E-Ink (status + UI hints)
