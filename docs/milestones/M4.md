## Architecture

```
┌────────────────────────────────────────────────────────┐
│  SynthNode (polyphonic, up to N voices)                 │
│                                                         │
│  Note event queue (lock-free RingBuffer)                │
│       ↓                                                 │
│  Voice allocation (find free / steal oldest)            │
│       ↓                                                 │
│  Per-voice signal chain:                                │
│    Oscillator → StateVariableFilter → VCA               │
│    (sine/saw/sq/tri)  (LP/HP/BP/Notch)  (amp envelope) │
│       ↓                                                 │
│  Stereo mix → left/right outputs                        │
└────────────────────────────────────────────────────────┘
```

## Voice Lifecycle

```
NoteOn  → find voice → reset osc/filter → trigger envs → active
NoteOff → release envs → env reaches 0 → voice idle
```

- Same note retrigger: finds existing voice for that note and retriggers
- Voice stealing: if all voices active, steals oldest (voice 0)
- Envelope parameters updated per-block from current SynthParams
