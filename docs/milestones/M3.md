# M3 - Drum Machine

## Status
Complete — all M3 deliverables implemented and tested.

## Goals

- [x] DrumNode — multi-pad drum sampler with per-pad parameters (tune, decay, pan, level)
- [x] StepSequencer — pattern-based step sequencer with velocity, probability
- [x] ADSREnvelope — exponential decay envelope for per-voice amplitude shaping
- [x] Engine integration — sequencer driven by transport position, triggers routed to DrumNode

- [x] chimera-play --drum mode — configurable BPM, per-pad sample loading, built-in test pattern
- [x] Unit tests — ADSR, DrumNode (mono/stereo, pan), StepSequencer (pattern, triggers)

## Architecture

```
┌──────────────────────────────────────────────────────────┐
│  Engine::audio_callback()                                 │
│                                                           │
│  1. transport_position += num_frames                      │
│  2. sequencer_.advance(pos, sr) → vector<StepTrigger>    │
│  3. for each trigger: drum.trigger(pad, velocity)         │
│  4. graph_.process(num_frames)                            │
│     → DrumNode::process() drains trigger queue            │
│     → plays samples with ADSR envelope, pan, level        │
│     → mixes to stereo output                              │
│  5. MasterOutputNode → backend playback                   │
└──────────────────────────────────────────────────────────┘
```

## Pad Model

Each pad in DrumNode has:
- Loaded WAV sample (mono or stereo)
- `tune` (0.5–2.0): playback speed factor
- `decay`: ADSR decay time in seconds
- `pan` (-1..1): stereo panning for mono samples
- `level` (0–1): output level multiplier
- Lock-free `RingBuffer<DrumTrigger>` for cross-thread trigger injection

## Step Sequencer Model

- Configurable pads × steps grid
- Per-step: active, velocity (0–1), probability (0–1)
- BPM-driven step advancement tied to transport frame position
- `frames_per_step = (60/bpm) / steps_per_beat * sample_rate`
- Probability check: `rand()/RAND_MAX <= probability` before triggering
- Pattern name, dynamic step count (1–64)
