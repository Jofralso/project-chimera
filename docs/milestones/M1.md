# M1 - Audio Engine

## Status
In progress — ALSA backend complete.

## Goals

- [x] ALSA audio backend (PCM playback, float/s16, auto device)
- [x] AudioBackend abstraction (pluggable interface)
- [x] Auto-detection: ALSA → Dummy fallback
- [ ] JACK / PipeWire backend implementation
- [ ] Real audio capture (AudioInputNode → system input)
- [ ] Multichannel support (≥ 8 channels)
- [ ] Sample-accurate timing
- [ ] Transport control (play/stop/position)
- [ ] BPM / time signature management

## Exit Criteria

- [x] Audio plays through system output via ALSA
- [ ] Latency < 10ms end-to-end
- [x] Plugin instantiation via PluginHost works with real audio
- [x] Graph can be modified while audio thread is running (lock-free)
- [x] Session can be saved/loaded with active audio

## Current State

- **AudioBackend** interface: `init/start/stop/shutdown/running/name/set_process_callback`
- **ALSA backend**: opens `default` PCM, float or S16_LE, auto sample rate/channels/period size, `snd_pcm_writei` with xrun recovery
- **Dummy backend**: timer-driven (100% CPU-independent, for dev)
- **Auto backend selection**: `"auto"` type picks ALSA if compiled, else Dummy
- Audio I/O nodes: stubs (silent passthrough, ready for JACK wiring)
- Plugin ABI and host implemented
- Audio graph with topological sort processing

## Next Actions

1. Implement JACK client backend (process callback)
2. Wire AudioInputNode to system capture ports
3. Wire AudioOutputNode to system playback ports
4. Add transport state to engine
5. Implement sample-accurate parameter changes via control queue
