# M2 - Audio I/O, Effects, and Sampler

## Status
Planning

## Goals

- [ ] ALSA capture (AudioInputNode → system mic/line input)
- [ ] AudioOutputNode wired to system playback (separate from MasterOutput)
- [ ] Buffer/effects node (gain, volume, pan)
- [ ] Sampler node (wav file playback from disk)
- [ ] WAV file loader (16/24-bit, mono/stereo)
- [ ] Session playback mode (load and play a .chimera session)
- [ ] Real-time parameter changes via control queue
- [ ] Transport state (play, stop, position, loop)

## Exit Criteria

- [ ] Record audio from system input and play back through graph
- [ ] Load a .wav file and play it through a SamplerNode → effects → output chain
- [ ] Change parameters (volume, frequency) from control thread while audio runs
- [ ] chimera-play can load and play a saved session file

## Deliverables

- `AudioInputNode` reads from system capture (ALSA `SND_PCM_STREAM_CAPTURE`)
- `AudioOutputNode` writes to system playback ports
- `GainNode` — simple multiplier with parameter smoothing
- `SamplerNode` — loads .wav, plays on trigger, loop mode
- `WavLoader` — riff/wave header parser, float conversion
- `Session::play()` — load graph and start engine
- Transport state machine in Engine (play/pause/stop/position)
- Control-queue parameter updates wired through EngineMessage::SetParam

## Dependencies

- M1 engine foundation (complete)
- ALSA duplex (PCM capture in separate thread)
- libsndfile or manual WAV parser (prefer minimal dependency)

## Next Actions

3. Build SamplerNode (trigger, read/advance, loop)
