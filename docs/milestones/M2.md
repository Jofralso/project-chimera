# M2 - Audio I/O, Effects, and Sampler

## Status
In progress — WavLoader, GainNode, SamplerNode, ALSA capture, transport complete.

## Goals

- [x] ALSA capture (AudioInputNode feeds from system capture via backend)
- [x] AudioOutputNode wired to system playback (MasterOutputNode → backend)
- [x] Buffer/effects node (GainNode with linear ramp)
- [x] Sampler node (wav file playback, trigger, loop)
- [x] WAV file loader (16/24/32-bit PCM, IEEE float, mono/stereo)
- [ ] Session playback mode (load and play a .chimera session)
- [x] Real-time parameter routing (SetParam wired, GainNode ramping)
- [x] Transport state (play, pause, resume, stop, position, loop)

## Exit Criteria

- [ ] Record audio from system input and play back through graph
- [x] Load a .wav file and play it through a SamplerNode → GainNode → MasterOutput chain
- [x] Change parameters (gain via linear ramp) from control thread while audio runs
- [ ] chimera-play can load and play a saved session file

## Deliverables

- `WavLoader` — riff/wave header parser, float conversion (16/24/32-bit, PCM/IEEE)
- `GainNode` — multichannel volume with linear ramp for click-free changes
- `SamplerNode` — loads .wav, trigger/loop playback, multichannel output
- `AlsaBackend` — duplex capture stream (optional, falls back to silence)
- `Engine::audio_callback` — routes AudioInputNode ← capture, MasterOutputNode → playback
- `AudioGraph::find_node_by_class()` — master/input node lookup
- `TransportState` — Stopped/Playing/Paused/Loop with Engine pause/resume
- `EngineMessage::SetParam` — wired through mutation handler

## Dependencies

- M1 engine foundation (complete)
- ALSA duplex (capture in same thread as playback)
- Manual WAV parser (zero external dependencies)
