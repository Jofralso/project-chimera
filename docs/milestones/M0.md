# M0 - Platform Bring-up

## Status
Completed — see M1.md for next steps.

## Goals

- [x] Boot system (CMake build system, C++20 toolchain)
- [x] Audio engine initializes (Engine class, graph model, dummy backend)
- [x] Display output working
- [x] Input devices detected
- [x] CI pipeline active (build + test on push/PR)
- [x] Logging system active (Logger with levels, file output, macros)

## Exit Criteria

- [x] Basic audio plays from engine (TestToneNode → MasterOutputNode pipeline)
- [x] Device tree confirmed
- [x] End-to-end signal path validated (graph topological sort, node process chain)
- [x] Plugin ABI defined and tested (C ABI, dlopen-based loader)
- [x] Session save/load roundtrip works

## Deliverables

- CMake superbuild with realtime-safe compiler flags
- Real-time audio engine skeleton (Engine, AudioGraph, AudioNode, Port)
- Lock-free ring buffer for control/audio thread communication
- DSP graph model with topological sort
- Two built-in nodes: TestTone (source), MasterOutput (sink)
- Plugin Host: runtime scanner, loader, PluginNode wrapper
- Plugin SDK: pure C ABI (plugin.h), gain plugin example
- Session Manager: binary serialization, 60s autosave
- Logger: level-based, thread-safe, file/stderr output
- CI: build, lint, release workflows
