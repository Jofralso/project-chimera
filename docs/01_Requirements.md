# Requirements

## Audio

- 48kHz / 24-bit minimum
- <10ms latency target
- JACK or PipeWire backend
- Multi-device routing
- Live resampling

## Core Features

- Sampler
- Synth engines (subtractive, FM, wavetable, granular)
- Sequencer (piano roll + step + euclidean)
- DJ mode (beatgrid, sync, stems)
- Visualizer (FFT, oscilloscope, vectorscope)

## System

- Auto-save every 60s
- Crash recovery session restore
- Modular plugin system
- Real-time parameter automation
