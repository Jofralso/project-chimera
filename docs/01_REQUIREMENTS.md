# Project Chimera Requirements

## Goals
- Portable standalone music workstation
- <10 s boot target
- Low-latency audio
- Touch-first interface
- No keyboard/mouse required

## Hardware
- Raspberry Pi 5 (main)
- RP2040 (controls)
- ESP32 (wireless)
- Raspberry Pi Zero + eInk pHAT (persistent display)
- USB Audio Interface
- 7" TFT touchscreen

## Features
### Audio
- Multitrack playback
- Recording
- Routing
- Effects

### Sampler
- Record
- Slice
- Reverse
- Time stretch
- Chromatic playback

### Sequencer
- Step
- Piano roll
- Tracker
- Euclidean
- Probability
- Parameter locks

### Synth
- Subtractive
- FM
- Wavetable
- Granular

### DJ
- Cue points
- BPM detection
- Looping
- Beat jump
- Sampler
